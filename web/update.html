03 / FLASH CONTROL · DEVICE MAINTENANCE

固件更新与恢复。

这是源码公开版的 Web MIDI 更新工具。当前仓库不提供可刷写固件包；仅在你已自行取得可信且与设备型号匹配的文件，并了解恢复风险时，才选择本地 .fwsc 文件。NIGHTFALL 仍是实验项目，官方回退和无外置恢复器的场景尚未验证。

01 / IDENTIFY

连接并识别设备

尚未识别设备

使用桌面 Chrome / Edge、USB 数据线，并授予 MIDI（含 SysEx）权限。

02 / VERIFY

选择固件包

本仓库仅公开源码，不分发尚未通过完整实机、回退与恢复验证的 NIGHTFALL 固件包。选择文件后，网页会计算 SHA‑256 并检查结构与设备身份。

尚未选择。官方包请从 M‑VAVE 官网获取；其他开源包请核对其发布者和设备版本。

03 / BACKUP

备份与风险确认

刷写可能清除曲目、音色或采样，失败时可能需要专用恢复工具。NIGHTFALL 当前三个项目槽位只在 RAM 中；请先从同页实机编辑区导出 .nfpr 文件。本站的完整备份按钮仅适用于支持 Felucca 备份协议的设备。

04 / EXECUTE

明确执行

等待连接与校验

05 / REAL DEVICE TEST
刷后请在实机依次检查：开机身份、耳机/扬声器声音、全部琴键与旋钮、MASTER 音量、HOME 城市楼柱及声纹地形随演奏变化，以及 USB MIDI 和同页实机编辑区。若有异常，保留更新日志；官方 V15 包可能用于恢复，但从 NIGHTFALL 回退尚未在本机验证。
